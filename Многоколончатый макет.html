Что такое верстка сайта?

Верстка веб сайтов - разработка интерфейсной части сайта и перенос макета в веб. этим занимается верстальщик. умение верстать может стать первым шагом в карьере фронтед-разработщика.

    Для работы верстальщику нужно изучить:
  • Язык разметки гипертекста: HTML5
  • каскадные таблицы стилей CSS
  • Основы JavaScript
  • Принципы работы визуальных редакторов
  • Инструменты проверки валидности кода

    • Раньше было принято разделять верстку сайта на адаптивную,кроссбраузерную, семантическую; доступную и прочие категории. Сейчас основные инструменты верстальщика- языки HTML и CSS-шагнули далеко вперед, поэтому сайт сразу делают с учетом предпочтений пользователя и разных экранов, начиная с мобильного. Лучше сразу учитывать, как верстка страницы сайта будет смотреться на разных устройствах и программах. Поэтому в чистом виде верстка сайтов только одного типа не бывает, она должна быть одновременно кроссбраузерной, кроссплатформенной, валидной и семантической.

    Что такое валидная верстка сайта?

    Валидная верстка - это html код. который написан по апределенным стандартам. Их разработал Консорциум Всемирной Паутины - World Wide Web consortium (W3C). Валидность - соответствия html кода стандарта, которые позволяют сайту работать в разных браузерах и программах так, как было задумано. Валидность определяет, как на сайт будет реагировать поисковая системы и как его будут воспринимать пользователи. Проверить верстку сайта можно и вручную, и с помощью специальных сервисов или расширений в браузере. Например, с помощью сервиса Markup Validation Service? плагина Web Developer для chrome или в валидаторе W3C. Чтобы проверить код в валидаторе W3C, нужно загрузить в сервисе HTML-файл, фрагмент кода или вставить ссылку на сайт.

    Какая верстка считается качественной?

    1. Блочная - с применением "дивов"
    2. адаптивная. кросбраузерная - страница ведет себя корректно в различных браузерах и на мобильных гаджетах
    3. валидная - без ошибок в коде
    4. Текстовая.
